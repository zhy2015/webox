# Change Records

Create one short record for each meaningful delivery batch. Use `YYYY-MM-DD-short-topic.md` and include:

- scope and reason;
- files or modules affected;
- behavior and contract changes;
- migrations or configuration changes;
- verification performed and its result;
- known gaps and follow-up work;
- related commit hash when Git is initialized.

These records complement Git history; they do not replace clear commit messages or architecture decisions.
