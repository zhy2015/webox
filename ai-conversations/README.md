# AI Conversation Exports

Place the complete raw exports from every AI coding tool used on this project in this directory. The PRD explicitly rejects screenshots, excerpts, selected fragments, and post-hoc summaries.

Exports may contain prompts, generated output, tool calls, and environment details. Prevent credentials from entering AI conversations in the first place and inspect exports before delivery. If a secret was exposed, stop, rotate it, and document the narrowly scoped redaction; do not rewrite or selectively remove ordinary project conversation content. Never commit API keys, passwords, session cookies, or access tokens.
